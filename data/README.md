# Dados

Use esta pasta para organizar as bases do projeto:

- `raw/`: dados originais, sem alterações;
- `interim/`: dados intermediários;
- `processed/`: dados tratados para análise e modelagem.

As bases locais são ignoradas pelo Git para evitar o envio de arquivos grandes, credenciais ou informações sensíveis. Registre aqui a fonte, a data de acesso e o significado das variáveis utilizadas.
