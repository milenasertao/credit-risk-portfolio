# Credit Risk Portfolio

Projeto de portfólio para desenvolver e demonstrar habilidades em **políticas de crédito**, **análise de inadimplência** e **modelagem de risco** com Python.

## Objetivo

Construir uma análise completa de concessão de crédito, passando por:

1. compreensão e tratamento dos dados;
2. análise exploratória;
3. definição do público e da variável de inadimplência;
4. criação de variáveis explicativas;
5. desenvolvimento e avaliação de um modelo de risco;
6. proposta de uma política de aprovação;
7. acompanhamento dos resultados e documentação das decisões.

## Estrutura do projeto

```text
credit-risk-portfolio/
├── data/          # Orientações sobre os dados (bases reais não entram no Git)
├── notebooks/     # Análises exploratórias e experimentos
├── reports/       # Gráficos, tabelas e resultados finais
├── src/           # Funções e códigos Python reutilizáveis
├── .gitignore
├── README.md
└── requirements.txt
```

## Tecnologias previstas

- Python
- pandas
- NumPy
- Matplotlib e Seaborn
- scikit-learn
- Jupyter Notebook

## Como executar

```bash
git clone https://github.com/milenasertao/credit-risk-portfolio.git
cd credit-risk-portfolio
python -m venv .venv
```

No Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
```
